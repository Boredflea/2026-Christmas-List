# The Gilded List

### Christmas 2026, rendered in velvet, gold, and questionable judgment.

This is a gloriously over-the-top, completely front-end wishlist built for GitHub Pages. No backend. No build step. No npm. No framework. Just HTML, CSS, JavaScript, one logo, five obsessions, and a highly unreliable demand algorithm.

> **A demand level is not a measurement.** It is complete mumbo jumbo added strictly for dramatic effect. Please do not use it for science, finance, navigation, or emotional support.

## What lives here

| File | Purpose |
| --- | --- |
| `index.html` | The structure, the copy, the hierarchy of longing. |
| `styles.css` | The obsidian-and-gold visual system, animations, and responsive layouts. |
| `script.js` | The item data, filters, search, countdown, dossiers, and copy-to-clipboard behavior. |

## Features, because restraint is for cowards

- Full-screen gold-drenched hero with a live countdown to Christmas 2026.
- Tier filters and search across the collection.
- Card tilt, cursor glow, scroll progress, marquee, and reveal animations.
- Detail dossiers for every item, opened in a native dialog.
- Copy-to-clipboard for the whole list, with polite button feedback.
- Print stylesheet for handing the list to Santa in physical form.
- Reduced-motion support and keyboard-friendly controls.
- Mobile layout verified at 320px with no horizontal overflow.

There is no fake petition button. It was considered, admired, and banished for having no real purpose.

## Run it locally

From this folder:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Put it on GitHub Pages

1. Create a GitHub repository and push these files to the root of its default branch.
2. Open the repository **Settings**.
3. Go to **Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Choose the default branch and `/(root)`.
6. Save.

Your site will appear at something like:

```text
https://<username>.github.io/<repository>/
```
